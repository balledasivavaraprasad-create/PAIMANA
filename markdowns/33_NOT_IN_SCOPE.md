# Not In Scope for This Rebuild

These may be valuable later but should not block the frontend/backend redesign.

## 1. Re-training all predictive models

Keep existing models integrated through stable interfaces. Model retraining is a separate ML workstream.

## 2. Full live PAIMANA connector

Build the ingestion boundary so the connector can be added cleanly. Do not fake live connectivity.

## 3. Heavy learned clustering

Start with explicit peer matching. Learned clustering can be added after peer cohort quality is measured.

## 4. Full autonomous consequential intervention

Remain human-gated.

## 5. Large-scale external causal discovery

Do not claim causal identification beyond the evidence available.

## 6. Replacing every existing app component

Only replace components required by the new product structure.

## 7. Overly complex 3D interfaces

Avoid a 3D showcase that does not improve monitoring comprehension.

## 8. AI-generated arbitrary dashboard text

Analytics insight text should begin deterministic/data-backed.

## 9. “AI everywhere” architecture

Do not insert LLM calls where deterministic code is more reliable.
