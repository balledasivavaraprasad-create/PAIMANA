# Motion System

## Motion philosophy

The motion should feel like a premium analytical instrument.

Use motion to establish:

- hierarchy
- causality
- continuity
- state change

## Motion classes

### Micro

150–220ms equivalent:

- button hover
- focus ring
- dropdown
- chip state

### Standard

250–450ms:

- cards entering
- drawers opening
- chart transitions
- tab changes

### Major

500–900ms:

- landing hero reveal
- architecture walkthrough
- major page section choreography

Use sparingly.

## Landing page motion

Hero:

- text reveal
- intelligence graph activates
- one highlighted project trajectory

Scroll:

- section progress indicator
- controlled visual transitions

## App motion

Use minimal motion.

Examples:

- risk delta animates when it changes
- event pulse when newly created
- investigation steps appear progressively
- chart transitions between filters

## Prohibited motion patterns

Avoid:

- infinite floating cards
- excessive glass/reflection animation
- constant background movement behind data
- animated gradients that reduce text contrast
- motion that changes layout unpredictably

## Reduced motion

Provide static equivalents.
